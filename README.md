# Noto — A little space for what's next.

Noto is a lightweight, distraction-free daily task management web application built as part of the **Synent Technologies Web Development Internship (Task 5)**. Designed with a midnight-navy tech aesthetic, Noto emphasizes intentional typography, clean visual hierarchy, and snappy micro-interactions without relying on heavy frameworks or external UI libraries.

---

## ✨ Features

- **Task Management**: Add, complete, and delete tasks seamlessly with keyboard shortcuts (`Enter` to submit).
- **Dynamic Filtering**: Filter tasks in real time by `All`, `Active`, and `Completed`.
- **Live Metrics**: Automatic tracking of active task counts, completed tasks, and total entries.
- **Bulk Cleanup**: One-click action to clear all completed tasks.
- **State Persistence**: Uses native `localStorage` to retain tasks across page reloads and browser sessions.
- **Zero Framework Overhead**: Built exclusively with semantic HTML5, modern CSS3, and pure Vanilla JavaScript.
- **Fully Responsive**: Adapts fluidly across mobile (390px), tablet (768px), and large desktop displays (1100px+).

---

## 🎨 Visual Identity

- **Theme**: Cool Midnight Navy (`#091726`, `#0E2238`) paired with vibrant accent blues (`#4DA3FF`, `#8CCBFF`).
- **Typography**: Geometric sans-serif powered by Google Fonts' **Sora**.
- **Design Details**: Ambient background glow layers, custom accessible checkbox components, subtle hover reveals, and zero intrusive card wrappers.
